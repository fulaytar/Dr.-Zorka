# Zorka M.D. — Night Shift Simulator

Маленька браузерна гра: нічне чергування в лікарні. Одинадцять відділень,
нічні події з наслідками, мініігри, ZORKA OS, телефон, 23 секрети й
33 досягнення. Кожна наступна зміна відрізняється від попередньої.

Одна статична сторінка. Без збірки, без залежностей, без бекенду.

> Це гра. Усі пацієнти, показники, «діагнози» й назви препаратів вигадані
> для розваги — тут немає жодної медичної поради.

---

## Що є в грі

**Зміна.** 22:00 → 07:00. Час рухається від дій. Energy падає від роботи й
росте від кави; коли вона нижча за 15%, XP рахується наполовину.

**Приймальне.** Зал очікування з намальованими пацієнтами на стільцях
(на вузькому екрані — картки). Пул із 14 пацієнтів, щозміни в черзі випадкові сім. Ще троє
рідкісних з’являються лише за певних умов (залежать від рішень уночі).

**Нічні події.** 20 подій різної рідкості між відділеннями: вибило світло,
невідомий номер, шум у коридорі, зник тонометр, завідувач у піжамі.
У кожній — вибір. Частина рішень має відкладені наслідки: подія-продовження
через годину зміни, SMS, новий пацієнт, рядок у фіналі.

**Мініігри.** Крім наявних (ECG Challenge, стетоскоп, рефлекси, рентген,
Lab Detective, Code Blue) — п’ять тренажерів із трьома рівнями складності:

| Тренажер | Де | Механіка |
|---|---|---|
| Панель викликів | Приймальне | запам’ятати й повторити послідовність |
| Сигнальна панель | Emergency | перемикач змінює себе й сусідів, обмежені ходи |
| Системне сховище | ZORKA OS → System Vault | логічно підібрати пароль за підказками |
| Аварійний щиток | Ординаторська | розподілити потужність за умовами електрика |
| Дошка оголошень | Кімната персоналу | знайти, що змінилося |

І «Нічне замовлення» в медикаментозній: запам’ятати список і зібрати його
з переставленої полиці. Перемоги поспіль дають серію з бонусом XP.

**План на ніч і завдання дня.** Вісім пунктів плану ведуть по всіх
відділеннях (+20 XP кожен, +80 за весь список). Завдання дня змінюється
щодня; виконані поспіль дні рахуються в серію.

**ZORKA OS.** 14 програм: журнал нічної зміни, завдання, архів змін, профілі
колег, сховище з прихованими файлами, пошта з листами, що відкриваються
після певних подій.

**Телефон.** Вхідні дзвінки, історія викликів, SMS-гілки, які з’являються
лише після подій.

**Історії колег.** П’ять сюжетних ліній через події, наслідки й листування:
Олег із контейнером, інтерн Тарас, Катя з її кавовим клубом, Андрій із
качкою на знімку й Оля, яка по одній видає підказки до ще не знайдених
секретів. Три доведені до кінця історії дають окремий фінал ночі.

**Постійні пацієнти.** Хто вже був у тебе в попередній зміні, може прийти
знову — з новою скаргою і пам’яттю про те, як ти з ним повелася.

**Research Lab.** За трьома доказами (досьє, пацієнт №404, слід айтішника)
відкривається протокол ZM-07 — розв’язка історії з вибором, який діє на всі
наступні зміни.

**Кар’єра.** О 07:00 — підсумок: оцінка, один із семи фіналів, рядки про
твої рішення. «Наступна зміна» зберігає XP, досягнення, секрети й рівні
тренажерів, але дає нову чергу й випадковий тип ночі (гроза, повня, тиха
ніч, перевірка, нова кавоварка) зі своїми правилами.

## Деплой: GitHub → Vercel

1. [vercel.com/new](https://vercel.com/new) → **Import Git Repository** → обрати цей репозиторій
2. **Framework Preset** — `Other`
3. **Build Command** і **Output Directory** — лишити порожніми
4. **Deploy**

Vercel роздасть `index.html` із кореня. Кожен наступний `git push` у `main`
автоматично оновлює сайт. GitHub Pages теж підходить: Settings → Pages →
гілка `main`, корінь.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Уся гра: розмітка, стилі, логіка, SVG-графіка, синтезований звук |
| `vercel.json` | Заголовки безпеки (`X-Content-Type-Options`, `Referrer-Policy`) |
| `.gitignore` | `.vercel`, `node_modules`, сміття ОС |

**Єдиний зовнішній ресурс** — шрифти Google Fonts (Unbounded, Manrope,
IBM Plex Mono). Якщо вони не завантажаться, сторінка все одно працює:
у кожного шрифту прописаний системний fallback.

**Звук** генерується Web Audio API просто в браузері — жодних медіафайлів.
Вмикається й вимикається кнопкою у правому верхньому куті.

**Прогрес** зберігається в `localStorage` (ключ `zorkamd.v1`, поле `v` —
версія схеми; збереження першої версії гри мігрують автоматично). Якщо
браузер забороняє сховище, гра про це попередить і працюватиме без
збереження. Повне скидання: Телефон → Settings → «Скинути весь прогрес».

Код у `index.html` поділено на `<script>`-блоки за темами; усе нове
(події, дзвінки, тренажери, архів, фінали) — у блоці `NIGHT SYSTEMS`.

## Локальна перевірка

```bash
npx serve .
```

Або просто відкрити `index.html` подвійним кліком — гра працює і з
`file://`, лише шрифти підвантажаться з мережі.

## Адаптивність

Перевірено на 390px, 800px і повному екрані. Нижче 760px план поверху
перемикається на сітку карток, панель стану згортається до чисел, стіл
на головному екрані розкладається у два ряди, а тренажери складаються
в одну колонку.
