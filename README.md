# Zorka M.D. — Night Shift Simulator

Маленька браузерна гра: нічне чергування в лікарні. Одинадцять відділень,
мініігри, ZORKA OS, телефон, 20 секретів і 20 досягнень.

Одна статична сторінка. Без збірки, без залежностей, без бекенду.

> Це гра. Усі пацієнти, показники, «діагнози» й назви препаратів вигадані
> для розваги — тут немає жодної медичної поради.

---

## Деплой: GitHub → Vercel

### 1. Залити теку в GitHub

```bash
cd zorka-md
git init
git add .
git commit -m "Zorka M.D. — Night Shift Simulator"
git branch -M main
git remote add origin https://github.com/<ваш-нік>/zorka-md.git
git push -u origin main
```

### 2. Підключити репозиторій до Vercel

1. [vercel.com/new](https://vercel.com/new) → **Import Git Repository** → обрати `zorka-md`
2. **Framework Preset** — `Other`
3. **Build Command** — лишити порожнім
4. **Output Directory** — лишити порожнім (корінь репозиторію)
5. **Deploy**

Усе. Vercel роздасть `index.html` із кореня. Кожен наступний `git push`
у `main` автоматично оновлює сайт.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Уся гра: розмітка, стилі, логіка, SVG-графіка, синтезований звук |
| `vercel.json` | Заголовки безпеки (`X-Content-Type-Options`, `Referrer-Policy`) |
| `.gitignore` | `.vercel`, `node_modules`, сміття ОС |

**Єдиний зовнішній ресурс** — шрифти Google Fonts (Unbounded, Manrope,
IBM Plex Mono). Якщо вони не завантажаться, сторінка все одно працює:
у кожного шрифту прописаний системний fallback.

**Звук** генерується Web Audio API просто в браузері — жодних медіафайлів.
Вмикається й вимикається кнопкою у правому верхньому куті.

**Прогрес** (XP, рівень, досягнення, секрети, час зміни, налаштування звуку)
зберігається в `localStorage` браузера гравця. Сервер і база не потрібні.
Скинути — у грі: Телефон → Settings → «Почати зміну спочатку».

## Локальна перевірка

```bash
npx serve .
```

Або просто відкрити `index.html` подвійним кліком — гра працює і з
`file://`, лише шрифти підвантажаться з мережі.

## Адаптивність

Перевірено на 500px, 800px і повному екрані. Нижче 760px план поверху
перемикається на сітку карток, панель стану згортається до чисел, а стіл
на головному екрані розкладається у два ряди.
